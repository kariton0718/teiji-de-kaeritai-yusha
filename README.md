# 定時で帰りたい勇者 — Action RPG Prototype

魔王商事に現れる仕事の魔物を倒し、2つの能力を選び、魔王部長を倒して退勤ゲートから帰る短編の見下ろし型Action RPGです。HTML／CSS／JavaScriptとCanvas 2Dだけで動き、外部素材・外部サービス・追加パッケージは使いません。

## 起動

Node.jsが使えるPowerShellで実行します。

```powershell
cd 'C:\Users\owner\Desktop\ゲーム制作\定時で帰りたい勇者'
node server.mjs
```

[ゲーム](http://127.0.0.1:8179/)を開きます。起動済みならページを再読み込みしてください。停止は起動ターミナルでCtrl+Cです。サーバーは127.0.0.1限定で、外部公開しません。

このPCでNode.jsがPATHにない場合：

```powershell
& 'C:\Users\owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' server.mjs
```

## ゲームの流れ

タイトル → 操作説明 → 第1ラッシュ → 強化 → 第2ラッシュ → 強化 → 第3ラッシュ → 魔王部長戦 → 退勤ゲート → 結果です。未出現の予定敵を含め、ラッシュ内の敵を全滅させるまで次へ進みません。

制限時間は実時間5分。社内時計の17:45〜18:00に対応します。操作説明、強化選択、一時停止、ボス登場説明では時計・敵・弾・予告が止まります。気力0または時間切れで失敗。ボス撃破後も右上のゲートに到達するまで成功になりません。

## 操作

| 操作 | PC | 画面ボタン |
| --- | --- | --- |
| 移動 | WASD／方向キー | 方向パッド |
| タスク斬り | J／Space | 斬 |
| 既読スルーダッシュ | K | 避 |
| 有給の盾 | L | 盾 |
| 本日は退勤します | I | 必 |
| 決定 | Enter | ボタンをタップ |
| 強化選択 | 1〜3、←→／A・D＋Enter | 強化カードをタップ |
| 一時停止 | Esc | Ⅱ |

移動方向が向きとして残り、斬撃はその方向へ出ます。通常攻撃は押し続けても0.35秒間隔で連続します。画面ボタンは複数ポインターを別々に保持できるため、移動しながら攻撃・回避・盾・必殺技を使えます。

画面切り替え時は保持中のキーとタッチを解除し、実際に離すまで隔離します。直前のEnterや攻撃が次の画面へ流れません。画面を離れた場合も自動停止します。

## 戦闘

勇者は気力100、移動170px/秒。正面100度・約64pxの斬撃は20ダメージで、小型敵を押し戻します。一振りで同じ敵へ入るダメージは1回だけ。机・壁越しには当たりません。

回避は0.18秒無敵、再使用1.2秒。盾は2回で各1.5秒無敵。被弾後は0.8秒無敵になり、重なった敵から一瞬で連続ダメージを受けません。電話ゴーストの被弾は0.5秒だけ移動を遅くしますが、操作不能にはしません。

敵撃破で必殺ゲージが増え、100%で周囲132pxへ60ダメージ。ボスは一撃で倒せません。使用後も、その攻撃で倒した通常敵から得た分は再び蓄積します。

通常敵は以下の3種類です。

- 緑のタスクスライム：気力40。近づいて接触攻撃。
- 紫の未読メールバット：気力30。距離を取り、0.6秒の送信予告後に封筒弾。弾は机・壁・寿命で消え、同時最大8発。
- 桃色の電話ゴースト：気力50。着信表示後に方向固定の直線突進。突進後に隙があります。

出現地点は色付きの円で0.8秒予告し、勇者から離れた場所を選びます。予告中の地点と既存敵も考慮して配置し、出現後は敵同士を軽く押し分けます。倒すと紙片になって散ります。

## ラッシュと強化

- 第1：スライム4体
- 第2：スライム4体＋バット2体
- 第3：スライム3体＋バット2体＋ゴースト2体

第1・第2ラッシュ後に、未取得の強化から3つを提示します。選んだ強化はボス戦まで維持し、再挑戦でリセットします。各選択後、中央に気力24回復のコーヒーが1つ出ます。

- 二連タスク斬り：12ダメージの追撃と二重の軌跡
- 広域処理：射程＋24px、角度＋50度
- 迅速退勤：移動＋20%、回避待ち－30%
- 一斉返信：通常攻撃から11ダメージの貫通メール
- 有給追加：盾＋1、気力25回復
- 定時への執念：必殺ゲージ＋50%、必殺威力＋30

## 魔王部長

気力500。直線突進「ちょっといい？」は約1秒、円形攻撃「5分だけ会議」は約1.2秒予告します。突進方向は予告開始時に固定。机・壁へ衝突すると1.5秒気絶します。通常時は防御が固くダメージ35%ですが、気絶・攻撃後の隙は全ダメージが入るため、突進誘導が攻略の中心です。

気力半分以下で赤い「最終確認」状態になり、移動と攻撃間隔が少し速くなります。二つの攻撃は一つの状態機械で順番に行い、予告を重ねません。ボス気力は画面上部に常時表示します。

## 表示と設定

プレイ中は気力、実時間の残り分秒、社内時計、ラッシュ、盾、必殺ゲージ、取得強化、ボス気力を表示します。結果は成功／失敗、経過時間、撃破数、被弾数、取得強化を表示します。

画面揺れは初期ONで、右上の「揺れ ON/OFF」でいつでも変更できます。`src/config.js` の `screenShake` をfalseにすれば初期OFFです。音は初期OFFで、最初の操作後に右上からONにできます。音なしでも色・範囲・文字で全予告を判別できます。

速度、体力、攻撃、無敵、敵、ラッシュ、強化、ボス、制限時間、配置は `src/config.js` に集約しています。既存のCanvas描画、軸別衝突、幅優先探索、キーボード／複数Pointer入力をAction RPG用に再利用しました。

## 動作確認

```powershell
node --test tests/*.test.js
```

ロジックテスト22件で、移動・衝突、斬撃一回一判定、まとめ斬り、方向・射程・壁越し防止、押しっぱなし攻撃、回避／盾／被弾後無敵、敵弾、全強化、ラッシュ予定、停止状態、ボス攻撃、勝敗、完全リセットを確認しています。

状態を飛ばさない自動プレイも実施し、通常の移動・攻撃・回避・盾・必殺だけで全3ラッシュ、強化2回、ボスの両攻撃・最終確認・障害物気絶、退勤ゲートまで完走しました。最短判断をする自動操作では約47〜52秒でした。これは人が感じる3〜5分の目安や面白さとは別の到達可能性テストです。

[ブラウザー検証](http://127.0.0.1:8179/tests/browser.html)では、キーボードの開始から再挑戦、画面ボタン同時入力、停止・入力解除、強化選択、ボス、結果を実ゲーム上で確認できます。結合確認は状態設定を含み、通しプレイは位置・気力・時計・敵を変更しません。
