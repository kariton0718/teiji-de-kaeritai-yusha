# 定時で帰りたい勇者 — Auto Battle Story Edition

移動で敵をまとめ、自動攻撃と成長した技で仕事の魔物を倒す見下ろし型Action RPGです。6役職の魔王を突破し、退勤ゲートの先にあるエンディングを目指します。HTML、CSS、JavaScript、Canvas 2D、Web Audioだけで動きます。

## 起動

```powershell
cd 'C:\Users\owner\Desktop\ゲーム制作\定時で帰りたい勇者'
node server.mjs
```

ローカルURL：<http://127.0.0.1:8179/>

```powershell
node --test tests/*.test.js
```

## 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD／方向キー | ステージ上の任意位置を触ってスライド |
| 通常攻撃 | 自動 | 自動 |
| 必殺技 | K／I | 右下の必殺技ボタン |
| メニュー | 方向キー＋Enter、数字キー | タップ |
| 一時停止 | Esc | 右上のⅡ |

スマホでは触れた位置に半透明スティックが出ます。14pxのデッドゾーンを越えると通常速度となり、つまみは半径46px内に収まります。指がステージ外へ動いても離すまで追跡します。必殺技は別の`pointerId`で処理され、必殺技の指を離しても移動は止まりません。UI、物語、強化、設定、ポーズを触ってもスティックは始まりません。

通常攻撃は0.35秒間隔です。230px以内で机や壁に遮られていない敵を探し、近い危険な敵を優先します。対象がなければ最後の移動方向を維持します。斬撃は従来どおり射程64px、角度100度、威力24から始まり、壁越し攻撃と同じ一振りの多重ヒットを防ぎます。

## スマホ画面

ゲーム中は`100dvh`基準の専用レイアウトに切り替わり、ページの縦スクロールを止めます。気力、必殺ゲージ、残り時間、ステージ名は上部に固定し、必殺技だけを右下へ重ねます。BGM、効果音、画面揺れ、物語再表示は右上の歯車へまとめ、設定値を`localStorage`へ保存します。

## 物語と音楽

初回の「冒険を始める」では4場面のオープニングを表示します。Enter、タップ、スキップに対応し、「次回から自動表示しない」を保存できます。歯車とタイトルから再表示できます。

最終ゲート到達後は結果画面の前に4場面のエンディングを表示します。THE END後は、同じ必殺技で再挑戦、別の必殺技で挑戦、物語再表示、タイトルへ戻るを選べます。

BGMはWeb Audioによる本作オリジナルです。オープニングとタイトルは弦風コード、低音リズム、金管風旋律を重ねて徐々に盛り上げます。通常戦、後半戦、ボス、社長、エンディングで曲をフェード切替し、気力25%以下では緊張音を加えます。外部音源は使用していません。

## 難易度と回復

| 攻撃 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 書類束スライム接触 | 9 | 12 |
| 封筒バット弾 | 8 | 11 |
| 電話ゴースト | 10 | 13 |
| 締切オーガ | 14 | 19 |
| 監視ドローン弾 | 9 | 12 |
| リーダー／係長 | 12／13 | 13／15 |
| 課長／部長 | 14／15 | 18／20 |
| 専務／社長 | 16／17 | 24／30 |

被弾後無敵は通常1.2秒、ボス戦1.5秒を維持します。気力50%以下でゲージ、画面端、主人公の疲労表現が変わり、25%以下では警告を強めます。

| 回復品 | 回復量 | 主な入手方法 |
| --- | ---: | --- |
| 給湯室のコーヒー | 最大気力の25% | 通常敵から3.5%、大型敵から34%、各ボス後に確定 |
| 栄養ドリンク | 最大気力の45% | ステージ3以降で1.2%、後半の緊急補給 |
| 定時の弁当 | 最大気力の70% | ステージ5以降で0.4% |

気力25%以下になると各ステージ1回だけ、安全な見える位置へ緊急補給が出ます。回復品は同時3個、14秒で消え、残り4秒から外周と秒数で知らせます。気力82%超では通常ドロップを止めます。

## ボスと机の衝突修正

以前は敵移動が全員12pxの勇者半径で判定され、大型ボスの見た目と当たり判定が机へ食い込む場合がありました。現在は各敵の実半径で出現、通常移動、高速移動、突進、着地を細かく判定します。近接攻撃はボス中心ではなく、主人公側の見えている体表まで遮蔽を調べます。机を完全に挟む攻撃は引き続き遮断します。

社長は第2・第3形態で組織再編を使います。机を切り替えた後、勇者、ボス、雑魚、回復品を半径込みで検証し、重なった対象だけを近い安全位置へ移します。退勤ゲートまでの経路も維持します。
