# 定時で帰りたい勇者 — Five Stage Action RPG

魔王商事の5ステージで仕事の魔物を倒し、技の習得と進化を重ね、魔王部長と魔王社長を突破して退勤する見下ろし型Action RPGです。HTML／CSS／JavaScriptとCanvas 2Dだけで動き、外部素材や外部サービスは使いません。

## 起動

```powershell
cd 'C:\Users\owner\Desktop\ゲーム制作\定時で帰りたい勇者'
node server.mjs
```

[ゲームを開く](http://127.0.0.1:8179/)。起動済みなら再読み込みしてください。サーバーは `127.0.0.1` 限定で、外部公開しません。

Node.jsがPATHにない場合：

```powershell
& 'C:\Users\owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' server.mjs
```

## 操作

| 操作 | PC | 画面ボタン |
| --- | --- | --- |
| 移動 | WASD／方向キー | 方向パッド |
| 通常攻撃 | J／Space、長押し可能 | 大きな「斬る」ボタン |
| 選択した必殺技 | K／I | 「必殺」ボタン |
| メニュー選択 | 方向キー／WASD | カードをタップ |
| 決定 | Enter、選択画面は1〜3 | ボタンをタップ |
| 一時停止 | Esc | Ⅱ |

移動と攻撃は同時入力できます。戦闘用の操作ボタンは増やしていません。画面切替時は入力を解除し、必殺技は押した瞬間だけを受け付けます。

## ゲームの流れ

タイトル → 操作説明 → 必殺技選択 → 営業フロア → 業務集中フロア → 役員フロア → 魔王部長 → エレベーター → 深夜サーバー室 → 社長室前エリア → 魔王社長 → 退勤ゲート → 結果です。

全ステージは2ウェーブです。

- 第1ウェーブ終了：取得済み技の進化を選択
- 第2ウェーブ終了：未取得の新技を選択
- 魔王部長撃破後：後半へ持ち込む新技を選択
- 魔王社長撃破後：強化画面を出さず、退勤ゲートを開放

進化候補は進化可能な取得済み技だけです。候補が1つなら1択のまま表示し、進化対象がなければ「気力40回復」と「必殺技ゲージ補充」を提示します。新技候補には未取得の技だけを表示します。

制限時間は実時間8分です。説明、必殺技選択、強化、ステージ紹介、ボス紹介、一時停止中は時計、敵、弾、予告、自動技、必殺技効果が停止します。ステージ移行時は最大気力の30%分を上限内で回復します。

## 初期攻撃と技

初期のタスク斬りは射程64px、角度100度、威力24です。表示した扇形と当たり判定に同じ値を使い、一振りで同じ敵には1回だけ命中します。机・壁越しには当たりません。

| 技 | 取得時 | 進化 |
| --- | --- | --- |
| タスク斬り | 初期装備 | 射程88px・145度 → 二連斬撃 → 4回ごとの全周斬撃 |
| 一斉返信 | 前方へ衝撃波 | 3方向 → 5方向・貫通 |
| 書類シュレッダー | 周囲を回る書類刃 | 3枚 → 4枚・半径拡大 |
| 承認サンダー | 近い敵へ自動落雷 | 連鎖 → 2本・最大4連鎖 |
| 締切メテオ | 密集地点へ範囲攻撃 | 範囲拡大 → 3地点 |
| 差し戻しブーメラン | 往路と復路で各1回命中 | 大型化・射程延長 → 威力・頻度上昇 |
| 自動処理ドローン | 追従1機が自動射撃 | 2機 → 高速射撃 |

ブーメランは同じ往路または復路で同じ敵へ多重ヒットしません。ドローンと分身は当たり判定を持たず、通路を塞ぎません。落雷とメテオは上空からの攻撃として障害物を越えます。

## 開始時に選ぶ必殺技

- 本日は退勤します：カメラ内の敵へ大ダメージを与え、カメラ内の敵弾を消去。発動後0.7秒無敵。
- 分身出勤：8秒間、分身2体が通常攻撃と一斉返信を50%威力で再現。
- 定時ラッシュ：6秒間、通常攻撃が高速全周斬撃になり、被ダメージを50%軽減。

必殺技ごとにゲージ獲得倍率を設定できます。効果中はゲージを再充填しません。HUDには選択した名前、準備状態、効果残り時間を表示します。

## 5ステージ

1. 営業フロア：64px・100度の初期斬撃を覚え、最初の進化と新技を得る。
2. 業務集中フロア：扇状メールと方向固定の予告突進。
3. 役員フロア：距離で攻撃を変える締切オーガと、3形態の魔王部長。
4. 深夜サーバー室：960×1280の広いマップ。射撃敵、大型敵、監視ドローンを指定戦闘エリアで迎撃。
5. 社長室前エリア：広いマップを進んだあと、魔王社長と最終決戦。

第4・第5ステージは480×640の表示範囲に追従カメラを使います。マップ外は映しません。画面端の矢印が次の戦闘エリアやゲートを示します。画面外の遠距離敵は攻撃を始めず、敵弾には寿命、最大数、主人公からの最大距離があります。「本日は退勤します」の対象もカメラ内だけです。

## 大型敵とボス

締切オーガの攻撃間隔は3.85秒から2.95秒へ短縮しました。遠距離では3方向の督促弾、近距離では予告円形攻撃を使います。押し戻しは25%だけ通り、金色の耐性リングで区別できます。

魔王部長は攻撃間隔を約17%短縮し、予告時間と反撃時間を維持しています。突進、会議範囲、書類弾、増援、連続突進、連続床攻撃を順番に使い、机へ突進すると気絶します。

魔王社長は2形態です。

- 稟議レーザー：固定した直線を1.35秒予告して攻撃
- 組織再編：予告後に机の配置を2種類で切り替え
- 緊急招集：上限内でスライムと監視ドローンを追加

組織再編後は、壁の中に重なった主人公と敵を最寄りの安全マスへ移し、経路探索を作り直します。攻撃は1つずつ状態遷移し、避けられない同時発動を行いません。

## 動作確認

```powershell
node --test tests/*.test.js
```

自動テスト21件で、初期攻撃、移動攻撃、壁越し防止、進化と新技の分離、候補不足、ブーメラン往復判定、追従ドローン、必殺技3種類、大型敵の距離別攻撃、魔王部長、追従カメラ、画面外射撃制限、魔王社長の全攻撃と地形変更、全5ステージ、勝敗、停止、再挑戦を確認します。

状態を飛ばさない自動操作では、遠距離中心構成が160.96秒、近接中心＋定時ラッシュ構成が172.94秒で完走しました。実ブラウザ上の加速通しプレイは163秒、149体撃破、6回被弾で成功しました。設定上の制限時間は480秒です。

[ブラウザー検証](http://127.0.0.1:8179/tests/browser.html)では、390×844の実ゲームでキーボード、スマホ相当の同時入力、必殺技、強化、カメラ、魔王社長、再挑戦、実行時エラーを確認できます。
