# 定時で帰りたい勇者 — Simple Controls Action RPG

魔王商事の3フロアで仕事の魔物をまとめて倒し、6回の技強化を重ね、三段変身する魔王部長を倒して退勤する見下ろし型Action RPGです。操作を「移動・通常攻撃・必殺技」の3種類に整理しました。HTML／CSS／JavaScriptとCanvas 2Dだけで動き、外部素材や追加パッケージは使いません。

## 起動

```powershell
cd 'C:\Users\owner\Desktop\ゲーム制作\定時で帰りたい勇者'
node server.mjs
```

[ゲームを開く](http://127.0.0.1:8179/)。起動済みなら再読み込みしてください。サーバーは `127.0.0.1` 限定です。停止は起動ターミナルで `Ctrl+C` です。

Node.jsがPATHにない場合：

```powershell
& 'C:\Users\owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' server.mjs
```

## 操作

| 操作 | PC | 画面ボタン |
| --- | --- | --- |
| 移動 | WASD／方向キー | 方向パッド |
| 通常攻撃 | J／Space、長押し可能 | 大きな「斬る」ボタン |
| 必殺技 | K／I | 「必殺」ボタン |
| メニュー決定 | Enter | ボタンをタップ |
| メニュー選択 | 方向キー／WASD | ボタンをタップ |
| 強化の直接選択 | 1〜3 | 強化カードをタップ |
| 一時停止 | Esc | Ⅱ |

移動と攻撃は同時入力できます。必殺技は押した瞬間だけを受け付けるため、キーや画面ボタンを押し続けても意図せず再発動しません。画面切替時は保持入力を解除し、キーを実際に離すまで次画面へ入力を流しません。

## ゲームの流れ

営業フロア、業務集中フロア、役員フロアを各2ウェーブ攻略し、毎ウェーブ後に技を取得・進化します。6回の強化後に魔王部長と戦い、撃破後に右上の退勤ゲートへ到達すると成功です。

制限時間は実時間5分で、社内時計の17:45〜18:00に対応します。説明、強化、フロア紹介、ボス紹介、一時停止中は時計、敵、弾、予告、自動技が停止します。フロア移行時は最大気力の30%分を上限内で回復し、回復量を表示します。各ウェーブ後のコーヒーも残しています。

## 技の取得と進化

- タスク斬り：さらに広い範囲 → 二連斬撃 → 4回ごとの全周斬撃
- 一斉返信：幅のある衝撃波 → 3方向 → 5方向・複数貫通
- 書類シュレッダー：防御範囲52pxの回転刃 → 3枚 → 半径74px・4枚
- 承認サンダー：離れた敵へ自動落雷 → 連鎖 → 2本・最大4連鎖
- 締切メテオ：密集地点へ落下 → 範囲拡大 → 3地点へ落下

最初の強化には必ず一斉返信を含めます。第1ステージ中の2回の候補には、初期斬撃を広げる技、遠距離技、または取得済み技の進化が必ず含まれます。最大段階の技は候補から除外します。

敵撃破による必殺ゲージ獲得量も増やし、第1ステージの敵だけで100%へ到達します。必殺技は画面全体の敵を攻撃し、敵弾を消し、発動直後0.7秒間はダメージを防ぎます。敵の危険予告は消さないため、発動後も移動が必要です。

## 敵の攻撃と難易度

第2・第3ステージは敵総数を維持し、出現間隔を広げて少数から徐々に増える構成にしました。バット射撃頻度、弾速、ダメージを下げています。電話ゴーストの突進と締切オーガの範囲攻撃は同時に1つだけ予告できます。

突進方向は予告開始時に固定され、発動後は追尾しません。床攻撃は通常移動で中心から範囲外へ出られる予告時間に設定しています。ステージ3の5方向メールとボスの5方向書類弾は、主人公の当たり判定が通れる角度間隔があります。

魔王部長の3形態と形態飛ばし防止は維持しています。突進速度を320から270px/秒、各種予告を1.0〜1.45秒へ延長。書類弾を5方向へ減らして間隔を広げ、連続突進も毎回1秒予告します。攻撃後と机への衝突後は弱点が露出し、広い斬撃で反撃できます。

## 設定

速度、威力、射程、角度、無敵時間、敵弾、出現間隔、同時数、ボス、回復量は [src/config.js](./src/config.js) に集約しています。

画面揺れと音は右上からON／OFFできます。音は初期OFFです。効果音はWeb Audioで生成し、音がなくても赤・紫の線、扇、円、番号で危険を判断できます。

## 動作確認

```powershell
node --test tests/*.test.js
```

自動テスト24件で、広い初期斬撃、複数同時命中、一振り一判定、壁越し防止、押し戻し、技の全段階、必殺ゲージと発動無敵、フロア回復、敵攻撃の同時制限、通常移動での床・突進回避、弾の通過間隔、全ステージ、3形態ボス、勝敗、停止、再挑戦を確認します。

回避・盾を使わない自動操作で、遠距離構成は86.83秒、近接構成は92.08秒で全編をクリアしました。設定上の制限時間は300秒です。この自動操作は危険を先読みするため、人間が遊びやすいことや実際の所要時間を保証しません。

[ブラウザー検証](http://127.0.0.1:8179/tests/browser.html)では、K／I必殺、長押し再発動防止、移動＋攻撃、スマホ相当の同時入力、メニュー、一時停止、ボス、再挑戦、実行時エラーを確認できます。
