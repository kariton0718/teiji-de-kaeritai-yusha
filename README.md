# 定時で帰りたい勇者 — 試作版0.2

17:45。残っているのは報告書・印刷・引き継ぎ。「あと少し作業するか、上司から逃げるか」を選び、全業務を完了させて定時退勤するローカルゲームです。

## 起動

Node.jsが使えるPowerShellで実行します。パッケージの追加インストールは不要です。

```powershell
cd 'C:\Users\owner\Desktop\ゲーム制作\定時で帰りたい勇者'
node server.mjs
```

[ゲームを開く](http://127.0.0.1:8179/) 。すでに起動中ならページを再読み込みしてください。停止は起動ターミナルで Ctrl+C。HTMLのダブルクリックではなくHTTPで開きます。

このPCのNode.jsがPATHにない場合：

```powershell
& 'C:\Users\owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' server.mjs
```

ポートを変更する場合は `$env:PORT=8180` を設定して起動します。サーバーは127.0.0.1専用で、スマホ等の別端末からは接続できません。外部公開・SNS接続／投稿・課金は実施していません。

## ゲームの流れ

1. 17:45から開始。18:00までの15分を実時間75秒に縮めています。主表示は残り秒数。
2. 3つの番号付き作業場所へ移動し、E／Spaceまたは「作業」ボタンを長押し。順番は自由です。
3. 長押し中はその場に留まります。離して逃げても、そのプレイ中の進捗は保存。離れている間は進みません。
4. 上司に接触するとゲーム時間が停止。ランダムな依頼に4択で返答します。
5. 返答結果を読み、「よし、仕事に戻る」で再開。3秒の保護と上司の1.2秒の休止で逃げ直せます。
6. 本来の3業務と追加業務をすべて終えると「業務完了！」。出口が開き、床と画面が明るくなり、紙吹雪・効果音・移動速度1.2倍で退勤ダッシュ。
7. 出口に入ると成功。0秒なら失敗。結果の4指標と称号を見て「もう一度、帰る」で再挑戦。

仕事の進捗はプレイ内だけの保存です。再挑戦・ページ再読み込みではリセットします。
ダッシュ中にも依頼は発生します。追加業務を受けた場合は出口が再び閉じ、その仕事を終えると再開門します。閉じることは返答結果にも明記します。
0秒の判定を仕事完了・脱出より優先します。

### 操作

- WASD／方向キー：移動。斜め移動は正規化。
- E／Space長押し：近くの未完了業務を進める。作業中は移動入力より作業を優先。逃げるときは作業キーを離す。
- 画面ボタン：方向と作業。複数ポインターに対応。指を離す／cancel／ボタン範囲外で解除。
- Ⅱ／Esc：一時停止。フォーカス喪失・タブ非表示でも自動停止し、再開操作が必要。
- 返答中・返答結果中もゲーム時計は停止。長押しキーを離した勢いで返答を選ばないよう対策済み。
- 音OFF／ON：Web Audioの短いオリジナル効果音。初期はOFF。音がなくても同じ情報を表示。
- 動きを減らすOS設定では紙吹雪を抑制します。

### 上司への返答

| 返答 | 結果 |
| --- | --- |
| 承知しました | 未完了の追加業務1件（4秒）。依頼に対応する作業場所で行う |
| 明日やります | 追加なし。追跡速度＋15px/秒、上限145px/秒 |
| 担当は部長です | 50%で回避。失敗時に追加業務1件 |
| 有給の盾 | 1プレイ1回、追加業務も速度上昇もなし |

ランダムな依頼は指定の4種類。直前と同じセリフは連続しません。盾を使った後はその選択肢を無効化します。ボタンの二重クリックで追加業務が重複しないようにしています。

### 称号

表示する指標はクリア時間（失敗時は経過時間）、接触回数、追加された仕事の累計、盾の残数。時間は返答・一時停止を除いたゲーム進行時間です。

成功時は次の順に判定します。

1. 残り10秒以下：ギリギリ退勤兵。
2. 45秒以内・接触1回以下・追加0件・盾が残る：伝説の定時勇者。
3. 追加3件以上：魔王商事の新たな管理職。
4. 追加0件・接触3回以下：華麗なる引き継ぎ職人。
5. その他：盾が残れば有給を守りし仕事人、なければ盾を使い切った帰宅王。

失敗時は追加3件以上で「魔王商事の新たな管理職」、それ以外は「議事録に敗れし者」。成功／失敗の見出しは称号とは別に表示します。

## 構成

- `src/game.js`：仕事の進捗、返答、フェーズ、追跡、勝敗、称号。乱数を注入可能にして確率分岐を検証。
- `src/config.js`：初期値・ステージ配置・依頼・称号条件。
- `src/pathfinding.js`：幅優先探索、通れる直線だけを使う経路短縮、衝突。
- `src/input.js`：移動・作業の長押し、入力解除、自動停止。
- `src/render.js`：コード描画の仮素材、作業位置、開門、紙吹雪。
- `src/audio.js`：外部音源なしの短い効果音。
- `src/main.js`：単一の描画ループ、HTMLの仕事一覧・4択・結果。
- `tests/`：ロジック・ブラウザー結合・通常入力での通しプレイ。

## プレイで判断してほしいこと

1. 作業のあと1秒を粘りたくなるか。上司が近づくと自然に逃げる判断が生まれるか。
2. 返答の代償が分かり、盾を使う場面に迷うか。「明日やります」連打が有利すぎないか。
3. 業務完了の開門・明るさ・加速・音で「帰れる！」と感じるか。
4. 称号を変えるため、接触や追加業務を減らして再挑戦したくなるか。

制作側の観察：追加業務を拒否し続ける通しプレイは余裕をもって成功します。速度上限の存在も含め、返答の駆け引きが十分かは未検証です。まずここをプレイ感想で判断し、必要なら次の変更を決めます。
