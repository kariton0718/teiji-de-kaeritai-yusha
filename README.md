# 定時で帰りたい勇者 — Six Ranks Action RPG

仕事の魔物をまとめて倒し、1プレイ中に7系統の技を取得・進化させ、リーダーから社長まで6役職の魔王を突破する見下ろし型Action RPGです。HTML／CSS／JavaScriptとCanvas 2Dで動きます。

## 起動

```powershell
cd 'C:\Users\owner\Desktop\ゲーム制作\定時で帰りたい勇者'
node server.mjs
```

[ゲームを開く](http://127.0.0.1:8179/)。サーバーは `127.0.0.1` のみで待ち受け、外部公開しません。起動済みの場合は再読み込みしてください。

Node.jsがPATHにない場合：

```powershell
& 'C:\Users\owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' server.mjs
```

## 操作

| 操作 | PC | 画面ボタン |
| --- | --- | --- |
| 移動 | WASD／方向キー | 方向パッド |
| 通常攻撃 | J／Space、長押し可能 | 大きな「斬る」ボタン |
| 必殺技 | K／I | 「必殺」ボタン |
| メニュー | 方向キー／WASD＋Enter、候補は数字キー | カードをタップ |
| 一時停止 | Esc | Ⅱ |

移動と攻撃は同時入力できます。画面切替時に入力を解除し、必殺技は押した瞬間だけ受け付けます。タブを離れると自動で一時停止します。

## 1プレイの流れ

各ステージは「開始演出 → 雑魚ウェーブ1 → 取得済み技の進化 → 雑魚ウェーブ2 → 役職ボス → 未取得の新技 → 次ステージ」です。最終ボス撃破後だけは新技画面を出さず、退勤ゲートへ向かいます。

1. 新人研修フロア／リーダー：メガホンの増援号令と予告突進
2. 承認フロア／係長：順番に落ちる巨大ハンコと広がる衝撃波
3. 複写フロア／課長：扇状書類弾と見分けられるコピー分身
4. 管理職フロア／部長：巨大定規の薙ぎ払いと障害物へ誘導できる連続突進
5. 役員フロア／専務：破壊可能な監視ドローン、交差レーザー、包囲射撃
6. 社長決裁フロア／社長：玉座機械の極太レーザー、扇状弾幕、順番床攻撃。体力帯で3形態

ステージ移行後は離れた場所を探す必要がなく、開始から約1秒で主人公の周囲に出現予告が始まります。HUDは「敵出現中」「残り○体」「ボス接近」を表示します。第4〜6ステージは720×960で追従カメラを使います。

制限時間は実時間9分です。説明、必殺技選択、強化、ステージ／ボス紹介、一時停止中は時計・敵・弾・予告・自動技・必殺効果が停止します。ステージ移行時は最大気力の30%分を上限内で回復します。

## 大量戦闘と成長

初期タスク斬りはFive Stage版の射程64px、角度100度、威力24を維持しています。机・壁越しと一振りの多重ヒットを防ぎます。

| 技 | 取得時 | Lv.3 |
| --- | --- | --- |
| タスク斬り | 初期装備 | 二連斬撃＋4回ごとの全周斬撃 |
| 一斉返信 | 前方衝撃波 | 5方向・貫通 |
| 書類シュレッダー | 周囲を回る書類刃 | 4枚・回転半径拡大 |
| 承認サンダー | 近い敵へ自動落雷 | 2本・最大4連鎖 |
| 締切メテオ | 密集地点へ範囲攻撃 | 3地点へ落下 |
| 差し戻しブーメラン | 往路と復路で各1回命中 | 威力・射程・頻度上昇 |
| 自動処理ドローン | 追従1機が自動射撃 | 2機が高速射撃 |

同時敵上限は34体から64体へ、装飾上限は190から220へ拡張しました。終盤ウェーブは60体以上を約3秒でまとめて出現予約します。敵数と同時攻撃数を分離し、危険予告は同時3系統まで、敵弾は60発までです。画面外の遠距離敵は攻撃を開始せず、残敵は画面端の矢印で案内します。

## 開始時に選ぶ5必殺技

- 本日は退勤します：カメラ内の敵へ大ダメージ＋敵弾消去
- 分身出勤：8秒間、無敵の分身2体が通常斬撃と一斉返信を50%威力で再現
- 定時ラッシュ：6秒間、高速全周斬撃＋被ダメージ50%軽減
- 残業ブラックホール：前方へ4秒設置、小型敵を吸引して継続ダメージ、最後に爆発
- 稟議キャノン：向いている方向へ2.8秒の太い貫通ビーム、範囲内の敵弾を消去

効果中のゲージ再充填は停止します。HUDには名前、準備状態、残り時間を表示します。選択画面には用途説明と動くプレビューがあります。

## ボスの強さ

6ボスは役職ごとに体形、色、武器を変えました。後半ほど攻撃間隔を2.45秒から1.45秒へ短縮し、警告時間は約1.1秒を維持しています。強化火力で形態を瞬時に飛ばさないよう、次の形態へ入る前に各攻撃パターンを最低1回予告します。攻撃後は金色表示の短い反撃時間となり、通常時よりダメージが通ります。

## ビジュアルと音

- 主人公：青いマント、顔、社員証、剣、歩行・攻撃・被弾差分
- 通常敵：書類束スライム、封筒翼バット、受話器ゴースト、締切スタンプのオーガ、監視カメラ型ドローン
- ボス：メガホン、承認ハンコ、コピー機、定規、指揮ドローン、玉座機械を大きな特徴として描画
- 味方攻撃は青・金・白、敵予告は赤・紫。輪郭と形でも区別

[タイトルロゴ](./assets/title-logo.svg)と[6ボス一覧](./assets/boss-lineup.svg)は独立SVGです。[タイトルイラスト](./assets/title-art.png)は組み込みの画像生成機能で制作した本作専用のオリジナル素材です。外部素材、権利不明素材、有料素材は使っていません。

BGMはWeb Audioでメロディー、ベース、コード、リズムを組み合わせたオリジナル曲です。タイトル、通常戦、後半戦、ボス戦、社長戦でテンポと旋律を切り替え、勝利時は短いファンファーレを鳴らします。BGMと効果音は別々に音量調整でき、場面転換、一時停止、タブ非表示で停止します。音は最初の「音 ON」操作後に始まります。

## 動作確認

```powershell
node --test tests/*.test.js
```

自動テスト15件で初期攻撃、移動攻撃、壁越し防止、進化／新技分離、5必殺技、ブラックホール、キャノン、敵密度と危険上限、6ボス、社長3形態、即時出現、追従カメラ、停止、敗北、再挑戦を確認します。

状態を飛ばさない60fps相当の自動操作では、遠距離中心構成が131.18秒・405体撃破、近接中心構成が185.09秒・403体撃破で、どちらも6ステージと退勤ゲートまで完走しました。設定上の制限時間は540秒です。この所要時間は最適化された自動操作の値で、人間の実プレイ時間ではありません。

ブラウザではタイトル、1〜5キーの必殺技選択、Enter進行、開始1.7秒時点の敵出現、BGM有効化と音量UI、スマホ相当の操作ボタン、終盤大量表示を確認しました。終盤ショーケースは検証環境で平均58fps、最大フレーム時間50.0msでした。計測はCodexアプリ内ブラウザ1環境のみです。
