# 定時で帰りたい勇者 — 試作版0.1

魔王商事のオフィスで、上司をかわして30秒以内に退勤するCanvas 2Dゲーム。外部ライブラリ、素材、サービスへの接続はありません。設計書は親フォルダーの `定時で帰りたい勇者_設計書.md` を参照しています。

## 起動

Node.jsが使えるPowerShellで以下を実行します。依存パッケージのインストールは不要です。

```powershell
cd 'C:\Users\owner\Desktop\ゲーム制作\定時で帰りたい勇者'
node server.mjs
```

ブラウザーで **http://127.0.0.1:8179/** を開きます。起動したターミナルで Ctrl+C を押すと停止します。`index.html` のダブルクリックはES Modulesの制約があるため使用しません。

Node.jsがPATHにない場合、このPCの同梱ランタイムでも起動できます。

```powershell
& 'C:\Users\owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' server.mjs
```

ポートが使用中なら、すでに起動している本ゲームのURLを開いてください。別ポートを使う場合は `$env:PORT=8180` を設定してから起動します。サーバーは127.0.0.1だけで待ち受けるため、このPC内専用です。

## 操作とルール

- 「退勤チャレンジ」で開始。方向キー／WASD、または盤面下の4方向ボタンを押し続けて移動。
- 青いマントと社員証が勇者。赤紫のスーツと角が上司。右上の緑の扉が出口。
- 30秒以内に出口へ入ると成功。机と外周の壁は通り抜けられません。
- 上司は2秒後から追跡。接触すると双方1.2秒停止、残り時間が3秒減ります。停止中も時計は進みます。
- 停止解除後は2秒間の保護。「対応済み」と輪郭で表示し、その間は上司をすり抜け可能です。
- 0秒になる判定を出口より優先。接触だけでは失敗しません。
- Ⅱ／Escで一時停止。画面非表示・フォーカス喪失でも自動停止し、再開ボタンで続行。
- 結果画面の「もう一度、帰る」で全状態をリセット。
- 音はありません。17:59は演出時計で、中央の残り秒数が実際の制限時間です。

## 調整と構成

`src/config.js` に速度、時間、ペナルティ、保護、開始位置、机・出口の配置を集約しています。論理盤面480×640、40pxタイルの12×16マップを等比表示します。

- `src/game.js`：状態・衝突移動・接触・時間・勝敗。小刻みな更新で衝突抜けを防止。
- `src/pathfinding.js`：幅優先探索と衝突を考慮した経路短縮。0.25秒ごとに追跡経路を更新。
- `src/input.js`：キー・複数ポインター・入力解除・自動停止。
- `src/render.js`：コードで描くオリジナルのドット絵風素材。
- `src/main.js`：単一の描画ループ、HTMLのHUDと画面遷移。

`node --test tests/game.test.js`：**11件すべて成功**。

開始から出口までの経路、移動速度・斜め正規化、机・壁の衝突、上司の迂回と接触、予告、足止めと保護、時間切れ優先、成功、停止、5回の再挑戦を確認。通常設定の上司を動かしたまま移動するシミュレーションでもクリアできています。

ローカルサーバー起動後、`http://127.0.0.1:8179/tests/browser.html` の「ブラウザーテストを実行」で結合テストを再現できます。再実行するときはページを再読み込みします。

ブラウザー結合テスト：**12項目すべて成功**。実ゲームの開始、WASD／方向キー移動と解除、画面ボタンの継続入力・解除・cancel・範囲外、フォーカス喪失で入力と時計を停止、再開、接触と保護、成功／失敗のHTML表示、再挑戦・連続3回の再挑戦、390px幅の横はみ出しを確認。

結合テストは合成入力を使い、成功／時間切れ画面の確認時はゲーム状態を設定しています。ポインターキャプチャのみ合成入力用に差し替えるため、実機タッチ操作の保証ではありません。

通常のゲームページでも開始・方向キー入力、上司の追跡と接触、保護表示、自然な時間切れを確認。PC表示と390×844相当の表示をスクリーンショットで確認しました。通常ページのコンソールにエラーはありませんでした。結合テストページではブラウザー側からMutationObserverのエラーが1件記録されました（ゲームコードは同APIを使用していません。発生元未特定、12項目は完走）。

未確認：スマホ実機のタッチ／複数指とネイティブなポインターキャプチャ、実際のタブ非表示・OSアプリ切替による停止、Safari／Firefox。自動停止のフォーカス喪失イベントと停止中の時間固定は結合テストで確認しています。
