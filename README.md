# 定時で帰りたい勇者 — 試作版0.3

17:45から報告書・印刷・引き継ぎを完了し、18:00までに退勤するCanvas 2Dゲーム。作業は長押し、離れても途中進捗が残ります。外部サービス・素材・ライブラリーは不要です。

## 起動

Node.jsが使えるPowerShellで実行します。依存パッケージのインストールは不要。

```powershell
cd 'C:\Users\owner\Desktop\ゲーム制作\定時で帰りたい勇者'
node server.mjs
```

[ゲームを開く](http://127.0.0.1:8179/) 。起動中なら再読み込みしてください。終了はサーバーのターミナルでCtrl+C。HTMLのダブルクリックではなくHTTPで開きます。

Node.jsがPATHにない場合は、このPCでは以下を使用できます。

```powershell
& 'C:\Users\owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' server.mjs
```

ポート変更は起動前に `$env:PORT=8180` を設定。サーバーは127.0.0.1限定で、スマホなどの別端末からは接続できません。外部公開・SNS接続／投稿・課金は行っていません。

## 操作

- 移動：方向キー／WASD。作業：E／Space長押し。
- 会話：数字1〜4で即決。↑↓／W・Sで選択、Enterで決定。選択中は黄色の枠と矢印。
- タイミングゲージ：緑の範囲でSpace／Enter／「今だ！」ボタン。
- タイトル・結果：↑↓／W・S／Tabで移動しEnter。マウスクリックも可能。
- 画面の方向・作業ボタン、返答・判定ボタンでタッチ操作にも対応。
- EscまたはⅡで一時停止。画面を離れても停止。再開時は移動キーを押し直してください。
- 音は初期OFF。右上でON。音なしでも予告は見て判断できます。

会話・返答結果・ゲージ中はゲーム時計が止まります。ゲージには別の4秒制限があり、時間切れは失敗。一時停止中はゲージも停止します。押しっぱなしで決定が連続せず、画面切り替え時に移動入力を解除します。

## 4つの返答

| 返答 | 効果 |
| --- | --- |
| 承知しました | 4秒の追加業務が発生。上司の移動が8秒間45%に低下 |
| 明日やります | 追加なし、怒り＋1。速度・経路更新・先読みが強化。怒り3で選択不能 |
| 担当は部長です | ゲージ成功で追加なし・上司4秒停止。失敗で7秒の追加業務 |
| 有給の盾 | 1プレイ1回。追加・怒りの増加を回避。使用済み表示 |

盾は既にある怒りを消しません。返答結果を確認してEnterで再開すると3秒間の接触保護があります。追加業務は依頼内容に対応する既存の作業場所で行います。退勤ダッシュ中に追加されると出口は閉じ、完了すると再び開きます。

ステージごとに机・作業場所が異なります。部長は予告開始時の方向を固定し、予告中と気絶中には接触しません。減速は突進にも効きます。

3業務と追加業務を全部終えると、開門・画面の明るさ・業務完了表示・移動速度UP・音で退勤ダッシュへ。出口到達で紙吹雪と称号。結果にはステージ・時間・接触・追加業務・怒り・盾、特殊敵の統計を表示します。

## 保存と開発設定

最初は月曜のみ。クリアで水曜、次に金曜を解放。各ステージの最高称号と、その称号での最短時間も保存します。
保存はこのブラウザー・このURLのlocalStorage。別ブラウザー／別ポートとは共有されません。プレイ途中の位置や仕事進捗は再読み込みを越えて保存されません。

タイトルの「保存データをリセット」→確認で、このゲームの記録だけ削除。保存が使用できない環境では画面内に通知し、そのセッション内では遊べます。

`src/config.js` の `CONFIG.developer.unlockAllStages` をtrueにすると全ステージ選択可能。タイトルに開発設定を表示し、最高称号・解放の記録を更新しません。配布時の初期値はfalse。

## 調整・構成

数値と配置は `src/config.js` に集約。CONFIGに速度・怒り別の追跡・作業・保護・減速・ゲージ・会議・突進・称号、STAGESに曜日・配置・制限時間を定義しています。

- game.js：ゲーム状態、作業、返答、敵、結果
- pathfinding.js：衝突、ステージ別の幅優先探索
- input.js：長押し、メニュー入力、入力解除
- main.js：画面とゲームの接続
- progress.js：解放・最高称号の検証／保存
- render.js／audio.js：コード描画・効果音
- tests/：ロジックとブラウザー検証

最高称号の優先順位はprogress.jsのRANKS。上から高い順に「伝説の定時勇者」「華麗なる引き継ぎ職人」「有給を守りし仕事人」「盾を使い切った帰宅王」「ギリギリ退勤兵」「魔王商事の新たな管理職」「議事録に敗れし者」。同じ称号なら速い記録を保存します。伝説は初期設定で45秒以内・接触1回以下・追加なし・盾温存。残り10秒以内の成功はギリギリ、追加3件以上は管理職など、game.jsのrankResultで判定します。
