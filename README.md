# 定時で帰りたい勇者 — Chaos Action RPG Prototype

魔王商事の3フロアで仕事の魔物をまとめて倒し、1プレイ中に6回の技強化を重ね、三段変身する魔王部長を倒して退勤ゲートから帰る見下ろし型Action RPGです。HTML／CSS／JavaScriptとCanvas 2Dだけで動き、外部素材、外部サービス、追加パッケージは使いません。

## 起動

PowerShellで次を実行します。

```powershell
cd 'C:\Users\owner\Desktop\ゲーム制作\定時で帰りたい勇者'
node server.mjs
```

[ゲームを開く](http://127.0.0.1:8179/)。起動済みの場合は再読み込みしてください。サーバーは `127.0.0.1` 限定で、外部公開しません。停止は起動ターミナルで `Ctrl+C` です。

このPCでNode.jsがPATHにない場合：

```powershell
& 'C:\Users\owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' server.mjs
```

## ゲームの流れ

タイトル → 操作説明 → 営業フロア2ウェーブ → 業務集中フロア2ウェーブ → 役員フロア2ウェーブ → 魔王部長 → 退勤ゲート → 結果です。各ウェーブの全出現予定を含む敵を倒すと、毎回3候補から技を1つ取得・進化できます。合計6回の強化はフロアを越えて残り、再挑戦でリセットされます。

制限時間は実時間5分で、社内時計の17:45〜18:00に対応します。説明、強化、フロア紹介、ボス紹介、一時停止中は時計、敵、弾、予告、自動技が止まります。気力0または時間切れで失敗。ボス撃破だけでは成功にならず、右上の退勤ゲート到達が必要です。

### 3ステージ

- 営業フロア：スライム集団と単発メール。近接と衝撃波を覚える序盤。
- 業務集中フロア：敵数が増え、3方向の扇状メールと電話ゴーストの予告突進が重なる中盤。
- 役員フロア：5方向の弾幕、大量の小型敵、突進、締切オーガの予告範囲攻撃が出る終盤。

出現地点は事前に円で表示し、勇者の真上と障害物内を避けます。敵同士は押し分けられます。撃破時は紙片へ崩れます。

## 操作

| 操作 | PC | 画面ボタン |
| --- | --- | --- |
| 移動 | WASD／方向キー | 方向パッド |
| タスク斬り | J／Space | 斬 |
| 既読スルーダッシュ | K | 避 |
| 有給の盾 | L | 盾 |
| 本日は退勤します | I | 必 |
| 決定 | Enter | ボタンをタップ |
| 強化選択 | 1〜3、←→／A・D＋Enter | 強化カードをタップ |
| 一時停止 | Esc | Ⅱ |

移動方向を向きとして保持し、その方向へ攻撃します。画面ボタンは複数ポインターを保持でき、移動と攻撃などを同時入力できます。画面切替時は保持入力を解除し、キーを実際に離すまで隔離します。画面から離れた場合も自動停止します。

## 技の取得と進化

各系統はLv.3まで。同じ技を再び選ぶと進化し、カードに現在の段階と選択後の変化が表示されます。最大段階は候補から外れます。取得済みで進化可能な技を最低1つ候補に含め、最初の選択には必ず「一斉返信」を含めます。

- タスク斬り：範囲拡大 → 二連斬撃 → 4回ごとの全周斬撃
- 一斉返信：1方向衝撃波 → 3方向 → 5方向・複数貫通
- 書類シュレッダー：回転刃1枚 → 3枚 → 4枚・半径拡大
- 承認サンダー：自動落雷 → 連鎖 → 2本・最大4連鎖
- 締切メテオ：密集地点へ落下 → 範囲拡大 → 3地点へ落下

落雷とメテオは上空からの攻撃として机・壁を越えます。近接、衝撃波、回転刃は障害物越しに当たりません。回転刃には敵ごとの再ヒット間隔があり、落雷の連鎖先は1回の発動内で重複しません。複数技が同時に倒しても撃破報酬は1回です。

必殺技「本日は退勤します」は画面内全体へ届き、通常敵へ90、ボスへ45の基礎ダメージを与え、敵弾を消します。危険範囲の予告は消さないため、発動後も回避が必要です。

## 敵と魔王部長

- タスクスライム：集団で接近し、範囲攻撃の標的になる基本敵。
- 未読メールバット：距離を取り、営業では単発、業務集中では3方向、役員では5方向へ予告射撃。
- 電話ゴースト：視覚予告時に方向を固定して突進し、命中時は0.5秒だけ減速。
- 締切オーガ：やや高耐久。赤い円を約1秒予告して範囲攻撃。

魔王部長は気力720で、体力帯に応じて三段変身します。

1. 「ちょっといい？」の直線突進と「5分だけ会議」の円形攻撃
2. 7方向の書類弾と増援。突進・会議も継続
3. 方向を毎回予告する3連突進と、番号順に爆発する床。射撃・増援・会議も継続

各攻撃は1つの状態機械で順に発動し、危険予告を無制限に重ねません。高火力構成でも形態が消し飛ばないよう、各形態の代表攻撃を完了するまで次の体力帯で止まります。形態移行中は短時間ダメージを受けません。通常時は受けるダメージ60%、机・壁への突進衝突による1.5秒気絶と攻撃後の隙は100%です。防御中と弱点露出中は輪郭と文字で区別します。

味方攻撃は青・金・白、敵の危険は赤・紫で描き、色に加えて扇、線、円、番号、文字を使います。主人公を最後に描画し、大量エフェクト下でも位置を確認できます。敵30、敵弾48、装飾180などの上限を設け、画面外の弾と終了した演出を破棄します。

## 設定

気力、速度、攻撃威力、間隔、範囲、対象数、ウェーブ構成、敵、ボス、制限時間、同時数上限は [src/config.js](./src/config.js) に集約しています。

画面揺れは初期ONで、右上の「揺れ ON/OFF」から変更できます。音は初期OFF。最初のユーザー操作後にONへ切り替えられます。効果音はWeb Audioで生成し、外部音源を使いません。音なしでも全予告を判断できます。

## 動作確認

```powershell
node --test tests/*.test.js
```

ロジックと通しプレイの自動テスト21件で、壁・机との衝突、1振り1ヒット、壁越し防止、5技×3段階、候補生成、回転刃の再ヒット間隔、落雷の重複連鎖防止、敵弾と各種上限、無敵、停止、全6ウェーブ、3形態ボス、勝敗、ゲート、完全リセットを確認します。

状態を飛ばさない自動操作では、遠距離構成（一斉返信Lv.3＋承認サンダーLv.3）が90.55秒、近接構成（タスク斬りLv.3＋書類シュレッダーLv.3）が89.95秒で完走しました。これは先読みする自動操作の到達確認で、人が感じる面白さや実際の3〜5分目安を確認したものではありません。設定上の制限時間は300秒です。

[ブラウザー検証](http://127.0.0.1:8179/tests/browser.html)では、実ゲームでキーボード、画面ボタン同時入力、停止、6回の強化、ボス、結果まで確認できます。
