# 助っ人社員

- 総務の小春：7秒間追従、近距離かつ遮蔽物なしで気力12を最大3回回復。上限100。
- 営業の黒沢：8秒間追従、0.9秒ごとに3方向の貫通書類弾。威力18、貫通3体、射程260。
- 各階の通常敵8体撃破時に38%で抽選、当選時は各50%。各階最大1人。ボスとボス増援は条件に数えない。
- 味方は敵数・全滅判定に含めず被弾しない。ステージ移行と結果で退出。強化選択中は残り時間停止。
- 援護射撃とその連鎖爆発は必殺ゲージを増やさない。通常の主人公による撃破は従来通り。
- TOP名鑑に専用イラスト2枚と説明を追加。スマホの既存1枚幅表示を継承。裏ボス紹介は追加しない。
- 出現率、持続時間、回復量、火力はconfig.jsのalliesで調整。
