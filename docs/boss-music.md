# ボス専用音楽

既存Web Audio方式でオリジナルの3編成を追加。外部音源・権利不明の音楽は使用しない。

- 通常ボス：152 BPM、短調の反復弦楽風フレーズ、低音、打楽器、緊張感のある旋律。
- 社長：144 BPM、重厚な低音、金管風の重奏と合唱風の持続音、32音の主旋律。
- 特命監査役：174 BPM、半音を含む進行、高速の裏拍フレーズと終盤の打楽器追加。

音量を上げるだけでなく編成・旋律・進行を分ける。効果音と音量・ミュート設定は維持。ノイズ打楽器のバッファは再利用し、音源ノードを終了後に切断。
曲の選択をresolveMusicSceneに集約し、ボスのrankIndexで社長と裏ボスを区別。ゲーム状態がplayingのままでも撃破でボス曲を終了。同じ曲を毎フレーム再開しない。

機能テスト62件成功（曲の分岐、撃破時切替、音数・周波数・長さの有限性、ミュートを含む）。実機での聴感・スピーカー音量、ブラウザー再生は未確認。旧自動操縦通し2件は今回未実行。
部長・専務第2形態、黒沢強化、真エンディングと同じ制作ブランチ。公開は依頼後。
