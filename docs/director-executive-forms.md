# 部長・専務の第2形態を明確化

従来も内部的には2形態だったが、スプライト描画側の形態表記がなく、外見も同じだった。

- 部長：気力ではなくボスHP50%で鬼神部長へ。赤橙オーラと二本の定規状エフェクト。移動64→90、突進295→365、薙ぎ払い145→172、基礎攻撃26→30。三連突進、薙ぎ払い、横移動から突進。
- 専務：HP50%で機動要塞専務へ。紫オーラと周回する6機のドローン。移動52→76、高速移動455→540、基礎攻撃31→35。5か所の固定予告から番号順に爆撃、外周移動、交差レーザー、包囲弾。
- 両者とも1.4秒の変身、形態名バナーと頭上表記。変身時に古い敵弾・床攻撃を消去。新しい形態用の独立イラストではなく既存イラストにCanvas演出を重ねる。
- 高火力でもHP半分で必ず止まり、変身演出を飛ばして倒せない。
- 連続突進の回数が次の突進開始でリセットされる既存不具合を修正。三連突進後に反撃時間を確保。
- TOP図鑑の説明を更新。既存の助っ人追加を保持。
