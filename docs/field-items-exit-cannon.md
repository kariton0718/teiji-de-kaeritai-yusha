# 回復・時間制限アイテム／退勤案内／可動キャノン

1人用に実装。協力モードのゲームロジックは変更しない。

- drink の表示を板チョコ（45回復）、lunch をおにぎり（70回復）へ変更。既存ID・出現条件・緊急補給を維持。各192px透過WebPを新規生成し、戦闘中は50px表示、名称と回復量を併記。読み込み前には形の異なるCanvas描画で代替。
- 疾走シューズ：8秒、速度1.35倍。闘志の剣：8秒、プレイヤー攻撃1.5倍（味方援護は除く）。鉄壁の盾：8秒、被ダメージ30%減。
- 残業書類：5秒、速度0.65倍。2階以降。赤い警告・感嘆符・「危険 速度DOWN」を表示。出現時は主人公から65px以上離し、回収判定も通常より小さい。HPは減らさない。
- 同じ効果は残り時間を規定秒数に戻す。倍率・秒数の累積なし。異なる効果は共存し、速度UPとDOWNは乗算。メニュー中は減らず、階移動・リトライで解除。
- 強化・マイナスの出現判定は敵撃破時5.5%、成功後8秒クールダウン、同時2個まで。満タンでも出る。回復の最大3個とは別枠。既存回復ハイエナは回復アイテムだけを盗む。
- 社長・裏ボス撃破後は「ボス撃破！ あとは退勤しよう！」を常時表示。障害物を迂回する緑の道と退勤矢印、ゲート直近の矢印を表示。裏ボスのタイム条件とゲート到着判定を維持。
- 稟議キャノン：発動中に方向キー・WASD・スマホドラッグで照射方向を更新。無入力時は直前方向を保持し、通常攻撃の自動照準に奪われない。既存威力・時間・チャージ制限維持。
