# 黒沢の援護強化

利用者から「役に立たない」との感想を受け、既存の専用イラストと登場条件を維持して強化。

| 項目 | 変更前 | 変更後 |
|---|---:|---:|
| 援護時間 | 8秒 | 10秒 |
| 発射間隔 | 0.9秒 | 0.5秒 |
| 一発の威力 | 18 | 28 |
| 同時射撃 | 3方向 | 5方向 |
| 射程 | 260 | 360 |
| 弾速 | 310 | 390 |
| 貫通 | 3体 | 5体 |

扇状の射撃角は−16、−8、0、8、16度。壁を越えた敵を狙わず、弾数上限52を保持。援護撃破と連鎖爆発で必殺ゲージを増やさない。登場時メッセージとTOP図鑑を更新。
部長・専務の第2形態と同じ制作ブランチに保存。公開は依頼後。

検証：機能テスト57件成功。新規テストで従来射程外への発射、近距離3体の撃破、ゲージ増加なし、弾数上限、時間終了を確認。旧自動操縦の全通し2件は既知の難易度調整後の失敗があり今回未実行。実ブラウザー・スマホ実機のプレイ感は未確認。
