敵＋出現予告128、飛び道具160、予告攻撃28の上限。射撃準備中の雑魚も数を制限。敵弾は予告後に発射。射手を片づけると準備中の射撃が取り消される。突進は狙いを固定。線攻撃は線分との距離、速い弾は移動区間で当たり判定し、すり抜けを防ぐ。

ママは勇者の横へ移動。12秒ごとに190px以内で気力18＋強化量を回復。5秒ごとにタオルで135pxの敵に攻撃、175px以内の敵弾を消す。回復の光・援護の輪・実回復量・画面上の秒数を表示。ポチは以前同様、落ちた道具の回収とお願い補助。

道具：おにぎり気力25、ミルク必殺25、スニーカー8秒移動強化、グローブ8秒威力1.6倍、エプロン8秒被ダメージ半減。専用絵・足元の効果ラベル・取得表示・強化の残り秒数。遊び方と図鑑にも絵と説明。

初期装備はモップ＋連鎖泡。洗濯ばさみを実際に飛ぶ弾へ変更。アイロン貫通ビーム、往復するタオルブーメラン、落下予告の洗濯かごメテオを追加。8つの強化項目から選択できる。吸引渦、ビーム、弾の軌跡、衝撃線などで技を区別する。

## ボスと結末

夜は家事ボス5体＋寝かしつけ最終戦の6戦。子ども2人はひとつの寝かしつけ戦を担当。人間のかわいい姿のまま、HPも被ダメージもない。

家事ボスはそれぞれ3技を順に使用し、HP半分から頻度・範囲・弾数・増援が変わる。積み木落とし/突進、ソース弾/十字焼き、洗濯雪崩/吸引、水流/水弾、忘れ物弾/増援など。寝かしつけでは枕・おもちゃ列車・星の予告攻撃を避けながらお願いをかなえる。

夜のED後は任意で翌朝へ。起床・食事・歯磨き・着替えの4段階が終わると、専用イラストの「朝の時間ドロボウ」。時計弾、交差する針、朝の家事増援。倒すと子どもの送り出し演出→会社入口へ移動→出社のED。通常EDとは別。

図鑑は家族5＋雑魚15＋ボス7枠＋道具5＝32項目。寝かしつけ枠は男の子と女の子を並べて表示。
