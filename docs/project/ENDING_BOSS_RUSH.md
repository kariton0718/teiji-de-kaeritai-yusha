## 紙芝居

夜は寝かしつけ→夫婦のねぎらい→家族みんなで眠る3枚。朝は子どもを送り出す→父も出発の2枚から操作できる出社パートへ。真エンディングは会社へ到着→家族写真を見る→また定時に帰る決意の3枚。夜・朝の結果画面にもそれぞれ最後の絵を表示。

画像は組み込みimagegenで1枚ずつ生成。既存のtitle-keyart.webpを人物と画風の参考に使用。出発イラストは送り出し済みの子どもが映り込まないよう編集。子どもはかわいい姿のまま、攻撃対象外。

- 保存素材：`games/hayaku-netai-yusha/assets/story/night-01.webp`〜`night-03.webp`、`sendoff-01.webp`〜`sendoff-02.webp`、`true-01.webp`〜`true-03.webp`。
- 生成・編集プロンプトと原画像パス：同assetsの[ending-prompts.json](../../games/hayaku-netai-yusha/assets/ending-prompts.json)。元PNGは削除せず、ゲーム用は幅1000px・WebP品質90。

## 攻撃と難易度

| ボス | 新しい固有技 |
| --- | --- |
| おもちゃ | 時間差ドミノ、列車と十字攻撃 |
| フライパン | 戻るフライパン、残る焦げつき床 |
| 洗濯もの | 吸引とすき間付き弾幕、時間差プレス |
| 水あか | 渦の弾幕、安全なレーンが変わるシャワー |
| バッグ | 戻る鍵束、再予告つき連続突進 |
| 寝かしつけ | ひらひら毛布、すき間付きの星弾幕 |
| 朝の時計 | 順番に回る秒針、連続時計弾幕 |

各5技。戦闘ボスはHP60%未満・25%未満で加速し、間隔2.9→2.25→1.75秒。耐久1.8倍、ノックバック8%、移動速度増加。予告中に離れる・弾幕のすき間へ動く余地を確保。子どもはHPを持たず、お世話の進行で決着。

雑魚の移動1.12倍、射撃間隔2.2〜3.5秒、通常射撃2発・拡散5発。追加出現間隔は通常2.9秒・家族のお世話中3.8秒。回復の出すぎを抑えるためドロップ率8.5%→4.5%、通常撃破の必殺蓄積1.1→0.7。ママの回復・援護を維持。敵・予告上限128、敵弾上限112、全弾上限160で味方用の余裕を残す。
