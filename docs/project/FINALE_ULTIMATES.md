## 子どものラスボス

単純な5回の滞在から、3幕6ミッションへ変更。寝かしつけの進行で決着し、子どもをダメージ対象にしない。

1. 絵本を取って子どもへ届ける（2地点）。
2. 指定エリア内で魔物12体を片づける。立っているだけでは進まない。
3. 水をくんで届ける（2地点）。
4. 動く男の子の近くへ移動し、寝床へ誘う。
5. 輪の中で子守歌。離れると少し戻り、被弾で0.6秒分中断。
6. 男の子・女の子の順に布団をかける（2地点）。

各幕のバナー、ふたりの移動と台詞、話している子の動き。列車突進、枕の時間差落下、ふたりの星弾幕、毛布のレーン攻撃、おもちゃ大行進、追いかけ予告とロボ増援の6パターン。2.8→2.25→1.85秒で発動。騒音100では追加妨害を起こすが、完了済みミッションは取り消さない。

初回の通常増援70体、ミッション開始18〜26体、以降22〜30体を2.1→1.8→1.5秒間隔で追加。敵＋出現予告は128体上限を維持。

## 必殺技4種・再充填の修正

| 必殺 | 効果 |
| --- | --- |
| 本日は閉店です！ | 全体180ダメージ、一撃型 |
| お片づけ大旋風 | 4秒間、吸引＋周囲へ連続ダメージ |
| お星さま大そうじ | 3秒間、敵の地点へ星を5回落下 |
| 家族のふわふわ結界 | 気力20回復、6秒半減、周囲の弾消しと反撃 |

部屋に入る前に選択。戦闘中に切り替える追加ボタンは作らず、移動と必殺だけを維持。全種に発動時の敵弾・危険床消去あり。

原因は「必殺による撃破も通常のhurtEnemyと同じ充填経路に入る」こと。命中そのものではなく撃破で充填されていた。攻撃由来を明示的に伝播し、必殺の直接攻撃・遅延落下・飛び道具による撃破と、その撃破から生まれたミルクを充填対象外にした。効果中と終了後3秒は、通常撃破・ママ・ポチ・アイテムを含む全充填を停止。

通常撃破0.45、撃破由来は初期バッファ3・補充3/秒の上限。ミルク12、ポチ4、寄り道8。停止中ミルクの表示も「充填できません」に合わせた。ゲージ残量・発動中・再開まで秒数を表示。

## 敵の個性と全体の難易度

色と文字の役割マーク、移動残像、巨体、耐久バー、加速オーラで見分ける。ほこりは速さ138・半径9、タオルは速さ13・半径34・HP240。お皿は戻る弾、ロボは時間差3連射、泡は遅い大玉5方向、アヒルは速い小玉7方向、歯ブラシは予告後の最速弾、枕は予告地点への実際のジャンプ、列車は長距離突進、パンは短い高速突進。図鑑・遊び方も更新。

すべての敵ダメージを1.3倍して切り上げ（接触、弾、床、子どもの妨害を含む）。例：8→11、12→16、18→24、20→26。防御アイテムと結界の軽減はその後に適用。無敵時間0.85秒は維持。

## 裏ボス

従来5技に振り子ブーメラン・時間差タイムプレス・三重弾幕を追加した8技。攻撃間隔2.2→1.75→1.3秒。朝の敵10種の混成増援、初回64体、以降25〜31体を1.9秒／最終段階1.5秒間隔で追加。予告・安全なすき間・上限128体と敵弾112発を維持。

## 出社のラストラン

右スライド／右キーで走ると、住宅街→並木道→会社前へ背景が横スクロール。停止時には距離を進めない。光の粒・疾走線・通勤服の勇者の走る揺れ・区間表示・進行バー・専用BGM和音を追加。到着後2.2秒の光と「間に合った」の演出、ファンファーレから既存の真ED紙芝居へ接続。裏ボス撃破後は時間切れで勝利を取り消さない。

生成は組み込みimagegenを1素材ずつ使用。既存EDのtrue-01.webpを勇者の容姿の参考に使用。原画像を残しゲーム用WebPを追加。生成情報とプロンプト：[commute-prompts.json](../../games/hayaku-netai-yusha/assets/commute-prompts.json)。
