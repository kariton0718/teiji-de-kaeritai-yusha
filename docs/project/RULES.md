# シリーズ共通ルール

- 三浦雄介との個人制作。日本語で、やさしく具体的に説明する。会社用Googleドライブには保存しない。
- 最新のユーザー指示が優先。提案、決定、実装、検証、公開を区別する。
- main、制作ブランチ、未公開差分、AGENTS.mdを確認する。記憶・過去の添付・古いREADMEだけを最新版とみなさない。
- 修正前mainを保全ブランチまたはタグで保存し、作業ブランチで変更する。
- ゲームと無関係なファイルを変更しない。作品ごとの仕様・実装・素材・URLを分ける。
- 第1作のデータと既存公開URLは維持する。第2作の制作で第1作を上書きしない。
- 今回の変更について「公開して」など明示依頼があるまでmain反映・Pages公開を行わない。過去の承認は流用しない。
- 現在のPagesワークフローはmainへのpushで起動する。資料のみの場合も安易にmainへpushせず、制作ブランチを使う。
- ゲーム変更と関連資料を同じ制作ブランチへ保存する。保存先ブランチ・コミット、検証結果、未確認、公開の有無を報告する。
- スマホのわかりやすい操作、爽快感、絵と音の演出を大切にする。自動テストや自動操作成功を、実機での滑らかさ・面白さの確認に置き換えない。
- 新作の案は決定まで提案と明記する。出現条件や難易度を仮置きした場合も明記する。
- 第2作の子どもは演出上の対戦相手だが、悪魔化しない。角、邪悪な顔、魔王への変身などは付けず、かわいい子どものまま。寝かしつけ・お支度の進行で決着させる。
- ママと愛犬ポチは味方。攻撃対象に含めない。
