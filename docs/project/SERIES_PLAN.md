# シリーズ企画

## 共通の核（決定）

「日常の願い」をファンタジー風アクションにする。共感できるあるある、群れをまとめて片づける爽快感、簡単なスマホ操作、絵と音で伝わるドラマを重視。第1作と第2作のデータ・公開URLを維持・分離する。

## 第1作（既存）

定時で帰りたい勇者。会社で仕事の魔物・上司と戦い、退勤する。今回は更新をいったん区切る。既存作品は削除・置換しない。

## 第2作（ユーザーが採用済み）

- タイトル：早く寝たい勇者。同じ勇者が定時で帰宅したあとの物語。
- 舞台：家。家事、子どもの世話、寝かしつけ。アクションRPG。
- 雑魚敵は前作より多く。通常6体分のボス遭遇と裏ボス相当の朝の総力戦。
- 家事を片づけると家がきれいになる。子どものお願いへの寄り道・報酬。寝かしつけの静かな戦い。
- ママと愛犬ポチがお助けキャラ。
- 子どもは演出上の敵役・夜のラスボス。「まだ遊びたい」「起きたくない」など日常の反応を使う。悪魔っぽくしない。
- 通常エンディング：子どもを寝かしつけ、自分も無事に眠って終わる。
- 裏ルート：翌朝、起きない子ども、朝ごはん、歯磨き、着替えなどを乗り越える。子どもを送り出し、自分が出社するまでドラマチックに描く。
- 裏エンディングは通常版と別。「今日も、定時で帰ろう。」で第1作へつながる。
- 以前の「あと1本だけの悪魔」裏ボス案は撤回済み。夜ラスボスを悪魔へ置き換える案も採用しない。

## 試作に採用した具体化（今後調整可能）

- ママ：16秒ごとの気力回復＋周囲の家事を片づける。ポチ：落ちたアイテム回収、お願いの準備を一部進める。
- 家事ボス5体：散らかしゴーレム／焦げつきフライパン魔人／洗濯マウンテン／水あかドラゴン／忘れ物魔人「アレガナイ」。6番目は子ども「まだ、ねむくない！」。
- 移動＋自動攻撃＋必殺。子どもの依頼は光る輪に2秒とどまって進める。
- モップ旋風／泡バブル／お片づけ吸引／洗濯ばさみ連射／家族のチームワーク。
- 必殺「本日は閉店です！」。寝かしつけ中は静かな「みんな、おやすみ。」。
- 子どもには攻撃のダメージ判定なし。お願いをかなえることで決着。魔物への自動攻撃と子どもへの対応を並行する。
- 裏ルートは試作検証用に通常エンディング後から任意選択。正式解放条件の決定ではない。

## 残る判断・次の制作

1. 実プレイで敵の数、攻撃の気持ちよさ、家族のお手伝いの分かりやすさを調整。
2. ボス別の絵と技の個性、OP/EDイラスト・音楽の仕上げ。
3. 1プレイ8〜12分を初期目標としていたが、試作の自動操作は演出を除いて約4分。初見の実測を踏まえて時間・難易度を調整する。
4. 朝の正式な出現条件と、朝の失敗時の再挑戦範囲。
5. 第2作は既存サイト内の別パス`hayaku-netai-yusha/`で公開。第1作のURLは維持。
