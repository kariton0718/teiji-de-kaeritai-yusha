# 一時停止の廃止
- ボタン、Escによる一時停止、フォーカス喪失・タブ非表示による自動一時停止、再開画面、Gameのpause/resumeを削除。
- blur/visibilitychange時の入力解除は維持。戻った後は再開操作不要。
- 強化選択、ステージ開始、ストーリーの進行画面は維持。
- ブラウザ自身が背景タブの描画を抑制する挙動はそのまま。経過時間を一括で追いつかせる処理は追加しない。
- 一時停止ボタンの空き領域を削除し、スマホ盤面・名鑑の高さへ戻す。
- フォーカス喪失・非表示・Escの入力イベントを含む機能テスト48件成功。ブラウザ・スマホ実機は未確認。
- ゲームバランスは今回変更なし。従来の通しクリアテスト2件が敗北する既知の状況は継続。
- 制作ブランチ保存のみ。公開未実施。
