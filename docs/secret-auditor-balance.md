# 特命監査役・敵攻撃強化

## 内容
- 雑魚の攻撃力：スライム12→16、バット11→15、ゴースト13→18、オーガ19→25、ドローン12→16。
- 通常6ボスの基礎攻撃力：約30%増。増援のダメージ倍率0.4→0.55。
- 敵弾半径7→9、ボス弾8→10。扇状弾の広がり、オーガ・ハンコ・床・薙ぎ払いの範囲、レーザー幅を拡大。
- レーザー表示と予告の幅を実際の判定に合わせる。

## 裏ボス
- 架空会社「ノーリターン・コンサルティング」の特命監査役。
- 社長撃破後、実プレイ経過240秒以内（ちょうど240秒を含む）に退勤ゲートへ到達すると、一度だけゲートが閉じてボス紹介へ。
- メニュー・一時停止時間は含まない。9分の制限時間は継続。
- 出現時に必殺技ゲージを満タンにし、近くに栄養ドリンクを配置。勝手に戦闘開始せず、ボタンまたはEnterで開始。
- 小柄（半径18、社長35）、黒いスーツ、光る眼鏡、赤いネクタイ、書類ケース。
- HP2600、攻撃力38、通常移動135、高速移動620、突進390 px/秒。
- 3形態。横移動から突進、扇状弾、連続突進、分身移動、交差レーザー、包囲射撃、薙ぎ払いを組み合わせる。
- 撃破後にゲートが再開。エンディング冒頭・結果の称号が専用文言へ切り替わる。
- 240秒超なら通常エンディング。再挑戦時には出現・撃破フラグと到達時間を初期化。
- 出現条件は src/config.js の secretBoss.unlockSeconds、ボス設定は rankBosses[6] で調整。
