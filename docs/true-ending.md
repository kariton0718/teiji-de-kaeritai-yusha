# 裏ボス撃破後の真エンディング

通常クリアの4場面は維持。secretBossDefeatedがtrueの場合だけ、専用の4場面を表示する。

1. 特命監査役が鞄を閉じ、追加業務なしと告げる。
2. 退勤ゲートの書類の鎖が解け、社員たちも帰り始める。
3. 小春・黒沢と「お疲れさま。また明日」。
4. 家族のもとへ帰り、守りたかった時間を取り戻す。

イラストは新規生成した正方形2×2シート。専用CSSで各正方形を歪ませず表示。真エンディングの枠を金色に変更し、専用の穏やかな凱旋旋律をWeb Audioで追加。ミュート・音量設定は既存の設定を継承。
物語データはsrc/story.jsに分離。次へ・スキップ・結果画面での再生は既存操作を維持。再挑戦のresetで真エンディング条件をリセット。TOP図鑑には裏ボスの情報を追加しない。
確認用クエリ ?showcase=true-ending を追加（物語表示専用。クリア実績の確認ではない）。

画像：assets/story-true-ending-v1.webp。生成プロンプトはtrue-ending-generation.json。元生成画像を保持しWebPへ変換。
検証：分岐、再生・リセット、専用4場面、正方形レイアウトの自動検証。実ブラウザー接続制限のためスマホ実機と音の聴感は未確認。既知の旧自動操縦通しテスト2件は今回未実行。
