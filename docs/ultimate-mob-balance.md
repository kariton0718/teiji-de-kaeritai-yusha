# 必殺技と雑魚の調整
ブラックホールのゲージ係数0.9→1.3、キャノン0.85→1.3。他の必殺より溜まりやすくする。効果中＋終了後2秒の充填禁止、援護撃破の除外を維持。
分身8→9秒。選択画面と発動表示も更新。
スモッグの紫の沼を専用スロー状態に分離し移動速度40%、抜けて0.35秒で解除。電話ゴーストの既存68%スローは維持。
椅子、差し戻し鳥、CCメール、スモッグ、ハイエナ、カメレオンを各配置グループ2体増加。通常ウェーブ合計662→706体。スライム413体と同時64体上限は維持。図鑑はステージ設定から自動反映。
既存機能62件＋新規4件成功。実機プレイ未確認。旧自動操縦の全通し2件は今回未実行。部長・専務第2形態、黒沢強化、真エンディング、ボスBGMと同じ制作ブランチに保存。未公開。
