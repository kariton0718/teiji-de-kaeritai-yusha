## 起動

リポジトリのルートで次を実行し、表示されたローカルサーバーの`/games/hayaku-netai-yusha/`を開く。

```sh
python -m http.server 8179
# http://localhost:8179/games/hayaku-netai-yusha/
```

`file://`の直接オープンではES Modulesが動作しないためHTTPサーバーを使う。npm追加インストール、外部CDN、外部API、ネットワーク通信、課金サービス不要。

```sh
node --test games/hayaku-netai-yusha/tests/*.test.js
```

## 実装

- 夜：リビング→キッチン→洗濯→お風呂→明日の準備→子どもの寝かしつけ。家事ボス5体＋子どもの最後の遭遇。
- 家事戦：160〜320体を片づけてボス出現。初回72〜96体、以後も増援。敵＋出現予告の上限128、ボス用の1枠を保証。
- 遠くからの出現予告、弱い雑魚中心、広範囲の自動攻撃。撃破すると収納へ光が飛び、背景の散らかりが減る。
- 家事の途中に任意のお願い。対応で気力と必殺ゲージ回復。時間切れ・未対応に罰なし。
- ママ：16秒ごとの気力18回復（強化で増加）と周囲175pxの家事魔物を片づける。
- ポチ：アイテムを実際に追いかけて回収。12秒ごとにお届け／お願いの準備を0.5秒分進める。
- 子ども：HP・被ダメージなし、通常敵配列に含めない。光るお願いの輪に2秒とどまり、すやすや／お支度ゲージをためる。
- 寝かしつけ：5つのお手伝い。魔物が38体を超えると騒音が増える。100で進行−5、失敗へ直結しない。技は静かな演出に変化する。
- 夜のエンディング：寝息、毛布、ママ・ポチ・自分も眠る3場面。
- 試作の裏ルート：夜エンディング後の任意選択。翌朝、起床→朝ごはん→歯磨き→着替え、見送りの2場面、自分で会社入口へ走る操作、出社後の3場面。
- 別の裏エンディング：「今日も、定時で帰ろう。」。通常版と同一画像固定ではなく、場面に応じた描画を行う。
- スマホは画面の任意位置からスライド。単独の移動pointerIdを保持し、必殺技の別指を離しても移動を解除しない。Canvasの余白を補正して入力座標へ変換。
- PC：WASD/矢印、Spaceで必殺。一時停止ボタン・Esc停止・再開待ちメニューは撤去。フォーカス喪失時は入力だけ解除し、プレイを止めない。ページが非表示の間だけ進行を保留し、戻ると自動再開（経過時間を加算せず、押しっぱなしも解除）。第1作には影響しない。
- 初期音OFF。プレイ中の音ボタンでオリジナル合成BGM・効果音を開始。寝室は静かに、朝は速いテンポに切り替える。
- イラストはCanvasの図形で描いた仮素材。人間らしいママ・子ども、垂れ耳のポチ。子どもに角・牙・魔王化はない。

## タイムボタン撤去修正（未公開）

- ユーザー報告：タイムボタンが誤作動し、ゲームが進まない。
- 調査：クリック・Esc以外に、window.blurとvisibilitychangeも再開待ちの停止メニューを開いていた。実機で発生したイベントは未特定。
- 対応：手動停止と停止メニューを完全撤去。blurは入力解除のみ。非表示時の進行保留はメニューを出さず、表示に戻れば自動解除。
- 検証：既存18件＋コントローラーイベント回帰テスト7件。DOM代替で実際のmain.jsを実行し、フォーカス変更、非表示→復帰、キー・タッチの解除と再入力、ストーリーの維持を確認。実ブラウザー・スマホ確認ではない。
- 修正ブランチ：`codex/hayaku-no-pause`。保全：`backup/main-e36d22f-before-sleep-no-pause`。今回の公開依頼はまだないため未公開。
